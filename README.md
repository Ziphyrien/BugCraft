## 快速开始

要编译 BugCraft 网站，请按照以下简单步骤操作：

1. 使用 npm 或 yarn 安装依赖项：
   ```
   npm install
   # 或者
   yarn install
   pnpm install
   bun install
   ```

2. 启动开发服务器：
   ```
   npm run docs:dev
   # 或者
   <yarn/pnpm/bun> run docs:dev
   ```

3. 打开浏览器并访问 `http://localhost:5173`，即可查看您的文档网站。

## 可用脚本

- **`docs:dev`**：启动 VitePress 开发服务器。
- **`docs:build`**：构建生产环境的文档网站。
- **`docs:preview`**：预览已构建的文档网站。
